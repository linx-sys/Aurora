# Aurora · 极光音乐

一个纯粹、好用的 **Windows 本地 MP3 播放器**。纯原生程序（WPF + Media Foundation），零运行时依赖，任何 Windows 10 / 11 双击安装即可使用。

## 成品

**`AuroraPlayer-Setup.exe`（约 140 KB，自包含单文件安装包）**

- 双击运行 → 图形化向导 → **可自由选择安装目录**（内置文件夹树形浏览器 / 可编辑候选下拉，默认安装到用户目录，无需管理员权限）
- 安装选项：创建桌面快捷方式、**自动关联 MP3**（设为默认播放器）
- 自带卸载器（控制面板"应用和功能"或开始菜单均可卸载，音乐文件不会被删除）
- 支持静默安装：`AuroraPlayer-Setup.exe /S /D=D:\你的目录`

## 功能

| 功能 | 说明 |
| --- | --- |
| 文件关联 | 安装后双击任意 MP3 直接播放；同时加载其所在文件夹的全部音乐 |
| 单实例 | 已在播放时再次双击音乐，唤起现有窗口并切歌，不会开新进程 |
| 标签解析 | MP3（ID3v1 / v2.2 / v2.3 / v2.4）、FLAC（VORBIS_COMMENT + 内嵌封面）、M4A/MP4（iTunes ilst + 封面）、OGG/OPUS（VorbisComment）、WAV（LIST INFO / id3 chunk），均含封面与精确时长；智能识别下载器写入的占位标签（如 title=artist=album=kuwo），自动改用文件名信息 |
| 文件名推断 | 支持 `歌手 - 标题.mp3`、`歌手-标题.mp3`、`NN - 标题.mp3` 等常见命名，无标签文件也能正确显示 |
| 中文兼容 | 老歌 GBK 编码标签与 GBK 歌词文件自动识别，无乱码 |
| 封面 | 有内嵌封面直接显示；**无封面的歌曲按歌名自动生成专属渐变封面**（首字大字 + 歌曲信息，10 组极光配色），列表与播放页统一 |
| 播放页 | 点击封面进入全屏播放页：**唱机 + 旋转黑胶**（胶体颜色随歌曲配色变化、中央圆形封面、唱臂随播放/暂停搭下或抬起）+ 居中大字滚动歌词，`Esc` 或左上角返回 |
| 播放列表 | 底部列表按钮呼出抽屉：封面缩略图 + 标题/歌手/时长，单击切歌，当前播放高亮 |
| 音量 | 点击底栏音量图标弹出竖直调节条，拖动或点击调节 |
| 歌词 | 同名 `.lrc` 自动加载（`歌曲名.lrc` 或 `歌曲名.mp3.lrc`），逐行滚动高亮，点击歌词行跳转；无歌词的歌曲显示优雅空状态 |
| 真实频谱 | WASAPI 环回采集系统音频输出，56 段频谱实时律动（无声卡环境自动降级动画） |
| 播放列表 | 搜索（标题/歌手/专辑/文件名）、五种排序、单击播放、当前行均衡器动画 |
| 播放模式 | 列表循环 / 单曲循环 / 随机播放 |
| 记忆 | 记住上次打开的文件夹、音量、播放模式与主题，下次启动自动恢复 |
| 深浅主题 | 顶栏 🌙/☀️ 一键切换深色 / 浅色模式（歌词、列表、频谱全部联动） |
| 快捷键 | `空格` 播放暂停 · `←→` 快退快进 5 秒 · `↑↓` 音量 · `N/P` 下一首/上一首 · `M` 音量条 |
| 无边框圆角 UI | 极光渐变主题，Win11 系统级窗口圆角，可拖拽移动、边缘缩放、支持拖放导入文件/文件夹 |

> 关于"默认播放器"：Windows 10/11 保护用户对默认应用的选择。若系统已有其他播放器占用 MP3 关联，安装后会以"选择打开方式"提示一次，选 **Aurora → 始终** 即可完成关联；此前未装过播放器的电脑上双击 MP3 将直接由 Aurora 打开。任何情况下 Aurora 都会出现在"打开方式"列表中。

## 使用

1. 运行 `AuroraPlayer-Setup.exe`，按向导完成安装（可改安装目录）
2. 双击任意 MP3，或在播放器里点 **打开文件夹** / 直接把音乐文件（夹）拖进窗口
3. 卸载：`设置 → 应用 → Aurora 极光音乐`，或运行安装目录下的 `unins.exe`

`testmusic/` 内有 5 首合成的示例歌曲（含封面与歌词），可用于快速体验；不需要可整个删除。

## 构建

需要 Windows 10/11 + [.NET Framework 4.x](https://support.microsoft.com/windows/net-framework)（系统自带）与 [ffmpeg](https://ffmpeg.org)（仅用于生成图标）。无需安装任何 SDK：

```bat
build.cmd
```

依次产出：

- `build\AuroraPlayer.exe` — 播放器（免安装可直接运行）
- `build\unins.exe` — 卸载器
- `AuroraPlayer-Setup.exe` — 自包含安装包（内嵌上面两个 exe）

## 目录结构

```
MP3Player/
├── AuroraPlayer-Setup.exe   ★ 成品安装包
├── build.cmd                一键构建脚本
├── build/                   编译输出（免安装版在此）
├── assets/                  图标素材（app.ico / icon256.png）
├── src/
│   ├── App.cs               入口：单实例互斥、命名管道转发、关联标记
│   ├── MainWindow.cs        主窗口：播放控制/列表/歌词/频谱/快捷键/拖放
│   ├── ui.xaml              界面（嵌入资源，运行时 XamlReader 解析）
│   ├── Id3.cs               ID3v1/v2 标签与封面解析（UTF-8→GBK 宽松解码）
│   ├── Lrc.cs               LRC 歌词解析（多时间标签/offset/元数据）
│   ├── Model.cs             轨道模型、目录扫描、设置持久化
│   ├── Tags.cs              FLAC / M4A / OGG / WAV 标签、封面与时长解析
│   ├── Spectro.cs           WASAPI 环回采集 + FFT 真实频谱
│   ├── Assoc.cs             MP3 文件关联（HKCU，无需管理员）
│   ├── Installer.cs         安装向导（内嵌播放器/卸载器，支持 /S /D=）
│   └── Uninstaller.cs       卸载器（两阶段自删除）
└── testmusic/               示例音乐（可删）
```

## 已知限制

- AAC 裸流（.aac，ADTS）无容器标签，标题取自文件名，时长在首次播放后显示
- 频谱采集的是系统总输出（环回），与其他程序同时发声时也会随之律动
- 随机播放的"上一首"仅在本轮会话内有效
